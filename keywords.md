# Job Search Keywords

Live keyword list for the daily job agent. Read fresh on every run, so edits take effect next run.

How to manage:
- Add a term: put it under `## My additions` (tag it with a group, e.g. `[core]`).
- Disable a term without deleting it: put `~` before it, e.g. `- ~MongoDB`.
- Delete a term for good: move it to `## Removed` so a re-merge won't bring it back.
- Or just ask Claude: "add X to core", "disable Y", "remove Z".

Generated by merging `profiles/jd_profile.md` + `profiles/cv_profile.md` (see `extractor_prompt.md`). Last merge: 2026-11-15.

## Filters
- Location: Israel (hybrid / remote OK)
- Seniority: junior to mid (0–5 years)
- Max job age (days): 7
- Unknown posting date: exclude

Change "Max job age" to any number of days (e.g. 3, 10). "Unknown posting date" can be `exclude` (strict: only jobs with a confirmed date) or `include` (keep them, marked "date unknown").
